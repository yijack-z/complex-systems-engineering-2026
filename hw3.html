1系统目的

对应 9.5.2 System purpose

系统被开发的原因是：在机场、港口、铁路三种洲际通道渐近饱和的背景下，提供第四条骨干通道， 以真空管道消除空气阻力、以磁浮消除轮轨摩擦，把跨洲运输的时间成本压到小时级； 同时这条管廊作为结构骨架，为后续的能源输配、科研实验与轨道延伸提供共用基础。

2系统范围

对应 9.5.3 System scope

  • 命名：系统名称为"真空管道运输系统"（Vacuum Tube Transit System）。
  • 解决的问题：洲际运输在速度、容量、能耗三者间无法兼顾；既有通道受地理与航空管制刚性约束。
  • 做什么：在选定站点之间提供高速客运与夜间货运，并可在预约时段开放为真空实验环境。
  • 不做什么：不承担站内商业运营、不承担城市接驳。轨道站及其以上部分不在本期范围——竖直段止于近地轨道高度，顶端由端点接驳舱与轨道站对接，该对接接口只做预留、不纳入本期验证。
  • 应用与收益：跨洲通勤时间下降；沿线形成节点城市；能源与科研共用管廊降低单位投资。

3系统概述

对应 9.5.4 System overview（上下文 / 功能 / 用户特征）

3.1 系统上下文

系统处于"大洲运营商 — 跨洲管委会 — 站点运营单元"三层组织之中， 与外部电网、海关边检、既有交通方式、科研机构存在接口。系统内部由管段、泵组、闸门、 舱体、调度中心五类要素构成，边界定义见第 03 节控制结构框图。

3.2 系统功能

  • 在站间完成舱体的加速、巡航、减速与停靠。
  • 维持管内真空并监测漏率，异常时自动隔离。
  • 按日间客运 / 夜间货运 / 科研窗口三种占用方式调度管段。
  • 提供对外状态广播与事故通报。

3.3 用户特征

  • 乘客：一次性使用者，无培训基础，界面需极端易用。
  • 运维人员：专业岗位，需值守与检修权限。
  • 调度员：决策岗位，需全局态势与降级判断能力。
  • 科研用户：按预约使用，对真空度与振动更敏感。

对应 9.5.9 System operations（人的系统集成 / 可维护性 / 可靠性 / 其他质量）

  • SyRS-8-01：调度、检修、救援三类岗位的职责边界应在操作界面中可视化。
  • SyRS-8-02：安全关键操作（隔离、封段）应保留人工"更保守"方向的介入权。

8.2 可维护性（9.5.9.2）

  • SyRS-8-03：天窗时间内应能完成闸门或泵组的整模块更换（来源 UR-09）。

  • SyRS-8-05：单点失效不得导致全线瘫痪，只允许降级。

8.4 其他质量（9.5.9.4）

  • SyRS-8-07：系统应支持新增分支线与竖直延伸段而不重构主干。

11环境条件

对应 9.5.12 Environmental conditions

  • 自然环境：温湿度、盐雾（海底段）、冻融（极区段）、地质位移。

  • 法规环境：跨境运行涉及多国交通与环保法规。
  • SyRS-11-01：系统在上述环境下应保持规定的功能与安全性能。

03 系统控制结构框图 / CONTROL STRUCTURE

谁在控制谁

STPA 的第二步是建控制结构：找出控制器、执行器、传感器与被控过程， 以及它们之间的控制行为与反馈。没有这张图，后面的 UCA 分析就无从下手。

为什么这张图重要：STPA 不关心"部件会不会坏"，而关心"控制器在错误的信息下做了什么"。 图中每一个红色箭头，都是一个可能产生不安全控制行为的位置。

H-3闸门在舱体经过时闭合直接导致结构破坏与人员伤亡
H-4站内气闸误开站点与真空段之间失压，站内人员暴露

4.2不安全控制行为

05 安全需求与安全架构 / SAFETY

从 UCA 反推安全要求

每一条 UCA 都应被一条安全需求"堵住"，并落到架构上的一个具体机制。 这就是安全架构：不是加一个安全模块，而是把约束嵌进控制回路。

安全需求（SR-S）与对应架构机制
编号安全需求针对架构机制
SR-S-01闸门闭合前，系统应确认该隔离段内无舱体UCA-1 / SC-A闸门与区段占用检测硬互锁，位置反馈双通道
SR-S-02漏率超限时，系统应自动闭合对应闸门，不经人工确认UCA-2 / SC-B区段控制器内置自动隔离逻辑，人工指令不得覆盖

安全架构的三个原则

约束内嵌

安全约束放进控制回路本身（互锁、门控、表决），而不是事后加一道检查流程。

失效可控

任一单点失效只降级、不连锁；隔离段是失效传播的物理边界。

自动优先于人工

安全关键动作（隔离、拒发）由系统自动完成，人工只保留"更保守"的方向。

需要说明的边界：本节 STPA 只在概念层做定性分析，UCA 与场景取自公开方法框架下的小组推演， 未经专家评审，也缺少定量失效数据。它证明的是"我们识别出了哪些控制风险"， 而不是"这些风险已被消除"。
